# iPad 网页应用

这是“每日计划 · 时间投入”的 iPad Safari 本地网页应用（PWA）。界面针对 iPad 横竖屏和触控操作设计；添加到主屏幕后以独立窗口运行，任务数据保存在 iPad 本机，并支持 JSON 导入/导出。

## 在 iPad 上使用

**已发布地址：<https://hailaluluyu.github.io/daily-focus-ipad/>。** 可直接在 iPad 上用 Safari 打开。电脑上的 `file:///C:/.../index.html` 只能用于本机预览，不能用于 iPad 安装；主屏幕网页应用必须先从 HTTPS 地址加载。

1. 在 iPad 上用 Safari 打开上方网址，并保持页面打开，等待“数据”页显示“离线资源已缓存”。
2. 点 Safari“分享”→“添加到主屏幕”。
3. 从主屏幕启动应用；断网后仍可使用，任务、复盘和计时数据留在本机。

本应用没有后端接口，不会把计划数据上传到静态网站。清理 Safari 网站数据或删除主屏幕应用可能清除本机记录，请定期导出 JSON 备份。

也可以在电脑上启动本地预览服务器进行开发；iPad 访问电脑时需要与电脑处在同一局域网。正式安装到主屏幕建议使用 HTTPS。

## 主要功能

- 按日期管理任务，支持可选时间段、编辑、删除与重叠提示。
- 逐项复盘，未完成任务必须选择“松懈、取消、延后”之一；可重新编辑已复盘结果。
- 投入项计时，切换项目自动结束上一段；运行中的计时重开后继续累计。
- 月度计划完成率、未完成理由、每日趋势，以及日/周/月投入统计。
- 导出/导入 JSON 文件，便于在鸿蒙设备和 iPad 之间手动迁移数据。
- 每晚 21:30 后在应用前台显示待复盘提示。

## iOS 提醒说明

iPad Safari/PWA 无法像原生 HarmonyOS 应用一样可靠地安排本地后台定时通知。本版本在应用打开时检查 21:30 提醒条件；如需要应用关闭时也能收到通知，需要后续采用苹果原生 iPadOS 应用并配置 Apple 开发者签名及通知服务。

## 数据格式

导入文件使用版本化 JSON，包含 `schemaVersion`、`tasks`、`categories`、`sessions`、`reviewedDateKeys`。HarmonyOS 版与本版本使用相同的主要字段，可在任一端导出后手动导入另一端。导入会替换当前浏览器中的全部数据，请先导出备份。
